[폴더/파일 정리 자동화 프로그램 제작 실습 질의문]

프로젝트 폴더명 : File_Organizer_Project

1단계: 테스트 파일 200개 생성

MyWorkFolder 폴더 안에 아래 확장자를 랜덤하게 섞어 총 200개 파일을 생성해줘.
확장자 목록: doc, pptx, txt, pdf, hwp, exe, jpg, png, xlsx, csv, zip, mp3, py
생성/수정일을 2021년~2025년, 1~12월 범위에서 랜덤하게 지정해줘.

(실습 중 재사용을 위해 생성된 폴더를 압축 파일로 임시 백업해둔다)


2단계: GUI 기본 창 생성

tkinter를 사용해서 GUI 창을 만들고, 제목은 "File Organizer GUI", 크기는 600x400으로 설정하는 파이썬 기본 코드를 작성해줘. 아직 파일 정리 관련 기능은 없어도 된다.


3단계: 경로 선택 UI 추가

GUI에 [폴더 선택] 버튼을 추가해서 MyWorkFolder를 선택할 수 있도록 하고, 선택된 경로를 Entry에 표시되도록 해줘.


4단계: 정리 옵션 선택

옵션 영역을 만들어서 사용자 선택 가능하도록 해줘.
정리 기준: 확장자 / 날짜 / 둘 다 (Radiobutton)
날짜 기준: 생성일 / 수정일 (Radiobutton)


5단계: 미리보기 기능

[미리보기] 버튼을 누르면 MyWorkFolder 안의 파일들을 스캔해서 이동 계획을 출력하도록 해줘.
확장자별 정리라면: Images, Docs, Archives 등으로 분류
날짜별 정리라면: YYYY_MM 폴더로 이동 계획 생성
미리보기 결과는 Text 영역에 표시해줘.

<실행 오류시>
미리보기 버튼 없는데. 다시 수정해줘.


6단계: 실행 기능

[실행] 버튼을 누르면 실제로 파일이 이동되도록 하고, 이동 내역을 organizer_log.txt 파일에 기록해줘.
중복 파일이 있으면 _1, _2 형식으로 이름을 자동 변경해줘.

7단계: 진행 상태 표시
<앞에서 만든 임시 압축파일을  다시 풀어서 실습한다>

파일 이동 중에 GUI가 멈추지 않도록 threading을 사용해 작업을 실행하고, ttk.Progressbar를 사용해 진행 상황을 표시해줘.

<실행 오류시>
미리보기와 실행 버튼이 없어졌어 다시 만들어줘.


8단계: 되돌리기(Undo) 기능
<앞에서 만든 임시 압축파일을  다시 풀어서 실습한다>

최근에 이동한 파일 내역을 manifest.csv에 저장하고, [되돌리기] 버튼을 눌렀을 때 원래 위치로 복원되도록 해줘.


9단계: 파일 검색 기능
[검색] 버튼을 추가해서 선택된 폴더 안에서 파일명, 확장자, 수정일 범위를 조건으로 검색하고 결과를 하단에 출력하는 기능을 추가해줘.
