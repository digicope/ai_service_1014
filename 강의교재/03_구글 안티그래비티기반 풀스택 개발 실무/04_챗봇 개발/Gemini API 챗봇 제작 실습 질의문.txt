# Gemini API 챗봇 제작 실습 질의문

프로젝트 폴더명: Chatbot_Project

1단계: 기본 환경 준비
chatbot.py 파일을 만들고 Gemini API로 질문 1회 전송 후 답변을 출력하는 최소 코드를 작성해줘. 함수와 환경변수는 사용하지 말고 API 키는 코드에 직접 입력해줘.

모듈 설치:
pip install google-genai python-dotenv

2단계: Gemini 모델 변경
사용 가능한 Gemini Flash 모델을 확인하고 실습에 적합한 최신 모델로 변경해줘.

3단계: 환경변수 관리
API 키를 코드에 직접 쓰지 말고 dotenv로 불러와서  os.environ에서 읽어오도록 수정해줘.

4단계: 사용자 인터페이스 개선
질문 앞에는 You:, 답변 앞에는 Bot:을 표시해줘.

5단계: 함수 및 반복 실행
chat_with_gemini() 함수를 만들고 사용자가 quit을 입력할 때까지 대화를 반복하도록 수정해줘.

6단계: 대화 메모리
대화 히스토리를 리스트에 저장하고 이전 질문과 답변을 Gemini API 요청에 포함해 맥락을 유지하도록 수정해줘.

7단계: 오류 처리
try-except를 사용해 API 키 누락, 네트워크 오류, API 호출 실패 등을 처리하고 오류 메시지를 출력하도록 수정해줘.

8단계: 생성 파라미터 선택
temperature 값을 0.2와 1.0 중 선택할 수 있도록 메뉴를 추가해줘.

9단계: GUI 구현
기존 코드를 기반으로 chatbot_gui.py 파일에 Tkinter GUI 버전을 작성해줘. 질문 입력창, 전송 버튼, 채팅 영역을 구현하고 Enter 키로 질문을 전송할 수 있도록 해줘.

10단계: GUI 디자인 개선
배경색, 버튼 색상, 글꼴, 글자 크기, 사용자 질문과 Gemini 답변의 표시 형식을 개선하고 스크롤 기능을 추가해줘.

11단계: 대화 저장 및 조회
SQLite 데이터베이스를 사용해 대화 내용과 날짜·시간을 저장해줘. GUI에 History 버튼을 추가해 과거 대화 목록과 상세 내용을 조회할 수 있도록 구현해줘.

오류 발생 시:
대화 내용이 화면에 표시되지 않으면 API 응답 처리, Tkinter 화면 갱신, 스레드 사용, DB 저장 및 조회 코드를 점검해줘. 필요하면 queue와 after()를 사용해 수정하고 실행 가능한 전체 소스를 다시 작성해줘.

공통 조건:
최신 Google Gen AI SDK(google-genai)를 사용하고 Windows 환경에서 실행 가능한 코드로 작성해줘. 각 단계마다 수정된 전체 소스 코드와 실행 방법을 제공해줘.
