[실습 1] Gemini 활용 파이썬 기초 코드 학습 (초급)
실습 목표: 파이썬을 몰라도 AI에게 업무를 설명하고 계산 결과를 얻는 방법을 학습한다
-----------------------------------------------------------------------------------------
나는 프로그래밍 비전공자이며 AI 서비스 기획자이다. 
Google Colab Enterprise에서 실행할 수 있는 파이썬 코드를 생성해줘.

**실습 주제: 온라인 쇼핑몰 월간 매출 분석**

다음 조건을 충족해줘.

1. 가상의 쇼핑몰 상품 5개에 대한 상품명, 판매 수량, 단가 데이터를 만들어줘.
2. 각 상품의 매출액을 계산해줘.
3. 전체 매출액과 상품별 매출 비중을 계산해줘.
4. 매출액이 가장 높은 상품을 찾아줘.
5. 분석 결과를 표 형태로 출력해줘.
6. 마지막에 서비스 기획자가 이해할 수 있는 핵심 인사이트 3개를 설명해줘.

코드 작성 규칙:
- 파이썬 비전공자도 이해할 수 있도록 한글 주석을 작성해줘.
- 필요한 코드를 하나의 Colab 코드 셀에서 실행할 수 있게 만들어줘.
- 외부 파일이나 별도 패키지 설치는 사용하지 말아줘.
- 계산 결과를 임의로 작성하지 말고 실제 코드 실행 결과로 확인할 수 있게 해줘.
- 코드 아래에 각 단계의 역할을 쉬운 말로 설명해줘.

[실습 2] Antigravity 연계 파이썬 코드 자동 생성 (요구사항 기반 코드 생성)
실습 목표: 서비스 기획서의 요구사항을 실행 가능한 코드로 변환하고 결과를 검증한다.
-----------------------------------------------------------------------------------------
나는 개발자가 아닌 AI 서비스 기획자이다. 온라인 교육 서비스의 수강생 만족도 분석 기능을 기획하고 있다.

다음 요구사항을 만족하는 파이썬 프로그램을 생성해줘.

[서비스 요구사항]
- 가상의 교육과정 5개와 각 과정의 만족도 점수를 생성한다.
- 만족도는 1점부터 5점까지 사용한다.
- 과정별 평균 만족도를 계산한다.
- 평균 만족도가 4점 미만인 과정을 찾아 별도로 표시한다.
- 결과를 표로 출력한다.

[개발 및 검증 요구사항]
1. Google Colab에서 바로 실행할 수 있는 코드로 작성한다.
2. 필요한 경우에만 pandas를 사용한다.
3. 입력 데이터, 분석 로직, 결과 출력 부분을 구분한다.
4. 만족도 범위를 벗어난 값이 입력되면 이를 감지하는 검증 코드를 포함한다.
5. 실행 결과를 바탕으로 서비스 개선이 필요한 과정을 설명한다.
6. 비전공자가 이해할 수 있도록 코드의 주요 부분을 설명한다.

먼저 요구사항을 짧게 정리하고 코드를 생성해줘. 실행 오류가 발생하면 오류 원인과 수정 방법을 설명한 후 수정 코드를 제시해줘.

마지막으로 이 기능을 실제 교육 서비스에 적용할 때 추가로 필요한 요구사항 3개를 제안해줘.

[실습 3] NumPy·Pandas를 활용한 정형 데이터 처리 (데이터 분석 기초)
실습 목표: 표 형태의 데이터를 분석하여 서비스 의사결정에 필요한 정보를 추출한다.
-----------------------------------------------------------------------------------------
나는 AI 서비스 기획자이며 파이썬 비전공자이다.

온라인 쇼핑몰의 고객 구매 데이터를 분석하는 프로그램을 Google Colab용으로 만들어줘.

[데이터 조건]
- 고객 ID, 연령, 구매 횟수, 총 구매 금액, 고객 만족도 컬럼을 가진 가상 데이터 100건을 생성한다.
- NumPy를 활용해 분석에 사용할 수 있는 수치 데이터를 생성한다.
- Pandas DataFrame으로 데이터를 표 형태로 관리한다.

[분석 기능]
1. 데이터 상위 5건을 출력한다.
2. 구매 금액의 평균, 중앙값, 최댓값을 계산한다.
3. 고객 만족도의 평균을 계산한다.
4. 구매 금액이 상위 20%에 해당하는 고객을 추출한다.
5. 연령대별 평균 구매 금액을 비교한다.
6. 분석 결과를 바탕으로 고객 세분화 전략 3개를 제안한다.

[작성 규칙]
- Colab에서 바로 실행할 수 있게 작성한다.
- 필요한 라이브러리만 사용한다.
- 모든 분석 결과는 실제 생성된 데이터에서 계산한다.
- 각 분석이 서비스 기획에서 어떤 의미인지 설명한다.
- 데이터 분석 결과와 AI의 전략 제안을 구분한다.

마지막에 서비스 기획자가 확인해야 할 데이터의 한계와 추가로 수집하면 좋은 데이터 항목을 제시해줘.

[실습 4] AI 도구 기반 데이터 클렌징 자동화 (데이터 품질 관리)
실습 목표: 오류와 결측치가 포함된 데이터를 자동으로 정리하고 정제 기준을 수립한다.
-----------------------------------------------------------------------------------------
나는 AI 서비스 기획자이다. 고객 데이터를 활용한 AI 분석 서비스를 만들기 전에 데이터 품질을 점검하려고 한다.

다음 조건으로 데이터 클렌징 프로그램을 만들어줘.

[원본 데이터]
- 고객 ID
- 연령
- 구매 금액
- 만족도 점수
- 가입일

가상 데이터 20건을 생성하되 다음과 같은 품질 문제를 일부러 포함해줘.
- 연령 또는 구매 금액이 비어 있는 행
- 중복된 고객 ID
- 음수 구매 금액
- 만족도 범위를 벗어난 값
- 날짜 형식이 다른 데이터

[처리 기능]
1. 정제 전 원본 데이터를 출력한다.
2. 컬럼별 결측치 개수와 중복 행 개수를 계산한다.
3. 데이터 품질 문제를 유형별로 분류한다.
4. 각 문제의 처리 기준을 먼저 설명한다.
5. 결측치, 중복 데이터, 잘못된 값, 날짜 형식을 처리한다.
6. 정제 후 데이터를 출력한다.
7. 정제 전후 행 개수와 결측치 개수를 비교한다.

중요한 규칙:
- 데이터를 무조건 삭제하지 말고 삭제, 보정, 검토 대상으로 구분한다.
- 중복 고객 ID가 있다고 해서 구매 기록까지 무조건 삭제하지 않는다.
- 원본 데이터는 보존하고 정제 결과는 별도 DataFrame에 저장한다.
- 처리 기준을 코드 주석과 결과 설명에 명시한다.
- 데이터 정제 과정에서 변경된 사항을 요약 보고서로 출력한다.

마지막에 실제 서비스에 적용하기 전에 담당자의 승인이 필요한 항목을 알려줘.

[실습 5] Matplotlib·Seaborn 기반 데이터 시각화 (시각적 분석)
분석 결과를 차트로 표현하고 서비스 기획에 필요한 인사이트를 도출한다.
-----------------------------------------------------------------------------------------
나는 AI 서비스 기획자이다. 온라인 교육 플랫폼의 운영 현황을 한눈에 파악할 수 있는 시각화 결과물을 만들려고 한다.

Google Colab에서 실행할 파이썬 코드를 생성해줘.

[가상 데이터]
- 월별 신규 가입자 수
- 월별 유료 전환 고객 수
- 교육과정별 수강 신청자 수
- 교육과정별 수료율
- 고객 만족도

[시각화 요구사항]
1. Matplotlib과 Seaborn을 활용한다.
2. 월별 가입자 수 추이는 선 그래프로 표현한다.
3. 유료 전환 고객 수는 막대그래프로 표현한다.
4. 교육과정별 수료율을 비교하는 막대그래프를 만든다.

[기획 관점]

모든 그래프를 각각 출력하고, 마지막에 서비스 운영자용 핵심 인사이트 3개를 정리해줘.

[실습 6] 에이전트 연동 시각화 대시보드 고도화 (서비스 프로토타이핑)
실습 목표: 사용자가 자연어로 질문하면 데이터에서 근거를 찾아 답하는 분석 기능을 기획한다
-----------------------------------------------------------------------------------------
나는 AI 서비스 기획자이다. 교육 운영 데이터를 조회하고 자연어 질문에 답하는 AI 분석 대시보드의 시제품을 만들려고 한다.

Google Colab에서 실행할 수 있는 프로토타입을 생성해줘.

[데이터]
- 교육과정명
- 수강 신청자 수
- 수료자 수
- 수료율
- 평균 만족도
- 운영 월

[기능]
1. 가상 교육 운영 데이터 30건을 생성한다.
2. 데이터 요약과 주요 지표를 표로 보여준다.
3. 수료율과 만족도를 그래프로 표현한다.
4. 사용자가 "수료율이 가장 낮은 과정은 무엇인가?"와 같은 질문을 입력할 수 있게 한다.
5. 질문에 대해 데이터에서 확인한 값과 근거를 출력한다.
6. 데이터에 없는 정보는 추측하지 않고 확인할 수 없다고 답한다.

우선 LLM API 없이 규칙 기반으로 질문 유형을 처리하는 버전을 구현해줘. 이를 통해 데이터 조회와 자연어 인터페이스의 차이를 이해하고 싶다.

추가로 실제 Gemini API를 연동한다면 필요한 구성 요소, API 키 관리 방법, 비용 및 개인정보 보호 고려사항을 설명해줘.

주의사항:
- Colab에서 실행할 수 있는 범위와 별도 웹 앱이 필요한 범위를 구분한다.
- 단순한 규칙 기반 기능을 실제 AI 에이전트라고 과장하지 않는다.
- 기능별 구현 수준과 한계를 표로 정리한다.

[실습 7] Scikit-learn 기반 기초 예측 모델 (예측 서비스 기획)
실습 목표: 예측 모델의 입력, 출력, 성능 지표를 이해하고 서비스 적용 가능성을 검토한다.
-----------------------------------------------------------------------------------------
나는 AI 서비스 기획자이며 머신러닝 개발 경험은 없다.

교육 서비스에서 수강생의 중도 이탈 위험을 예측하는 기초 모델을 실습하려고 한다. 실제 개인 데이터가 아닌 가상 데이터를 사용해줘.

[가상 데이터 항목]
- 주간 학습 시간
- 최근 2주간 접속 횟수
- 과제 제출률
- 학습 진도율
- 중도 이탈 여부

[구현 요구사항]
1. 가상 데이터 500건을 생성한다.
2. Scikit-learn을 이용해 분류 모델을 만든다.
3. 학습 데이터와 테스트 데이터를 분리한다.
4. 기준 모델로 로지스틱 회귀를 사용한다.
5. 정확도, 정밀도, 재현율, F1 점수를 출력한다.
6. 혼동 행렬을 시각화한다.
7. 새로운 가상 수강생의 이탈 위험 예측 예제를 제공한다.

[기획자 관점 설명]
- 각 성능 지표가 무엇을 의미하는지 비전공자에게 설명한다.
- 이탈 위험을 놓치는 경우와 정상 수강생을 위험군으로 분류하는 경우의 차이를 설명한다.
- 이탈 예측 결과만으로 수강생에게 불이익을 주지 않는 운영 방안을 제안한다.

중요:
- 가상 데이터에서 발생한 결과를 실제 교육 서비스의 예측 성능으로 표현하지 않는다.
- 데이터 누수 가능성을 점검한다.
- 재현 가능한 난수 시드를 사용한다.
- 모델 성능이 낮더라도 결과를 숨기지 않는다.
- 마지막에 실제 서비스 적용 전 필요한 데이터와 검증 절차를 정리한다.

[실습 8] Gemini API 연동 및 모델 결과 활용 (생성형 AI 서비스 연결)
실습 목표: 파이썬 분석 결과를 Gemini에 전달해 자연어 해석과 서비스 보고서를 생성한다.
-----------------------------------------------------------------------------------------
나는 AI 서비스 기획자이다. 파이썬으로 분석한 교육 운영 데이터를 Gemini API에 전달하여 자동 분석 보고서를 생성하는 기능을 기획하고 있다.

Google Colab에서 실행할 수 있는 예제를 만들어줘.

[분석 데이터]
- 월별 가입자 수
- 유료 전환율
- 수료율
- 평균 만족도
- 예측 모델의 평가 지표

[구현 단계]
1. 가상 데이터를 생성하고 Pandas로 요약한다.
2. 실제 코드로 계산한 분석 결과를 딕셔너리 또는 JSON 형태로 구성한다.
3. Gemini API를 사용해 분석 결과를 자연어로 해석한다.
4. 서비스 운영자가 읽기 쉬운 보고서를 생성한다.
5. 데이터에 근거한 사실, 원인에 대한 가설, 추가 검증이 필요한 사항을 구분한다.
6. 핵심 지표와 개선 제안을 보고서 형식으로 출력한다.

[API 사용 규칙]
- 현재 공식적으로 지원되는 Google Gen AI SDK와 Gemini API 사용 방법을 확인해 적용한다.
- API 키는 코드에 직접 작성하지 않는다.
- Colab의 안전한 비밀정보 관리 기능을 활용하는 방법을 안내한다.
- API 키가 없거나 API 호출이 실패하면 파이썬으로 계산한 결과를 출력하는 대체 경로를 제공한다.
- 모델 이름은 실제 사용 가능한 모델을 확인해 설정할 수 있도록 한다.
- API 사용량과 비용, 개인정보 전송 위험을 설명한다.

나는 프로그래밍 비전공자인 AI 서비스 기획자이다. 파이썬 코드를 처음부터 직접 작성하는 것보다 AI를 활용해 업무 요구사항을 구현하고 결과를 해석하는 방법을 배우고 있다.

앞으로 코드 생성 시 다음 원칙을 지켜줘.

1. 먼저 내가 요청한 업무 요구사항을 쉬운 말로 정리한다.
2. Google Colab Enterprise에서 실행할 수 있는 코드를 생성한다.
3. 코드를 가능한 한 작은 단계로 나누어 제시한다.
4. 각 코드 셀의 목적을 한글로 설명한다.
5. 코드 실행 결과가 어떤 의미인지 설명한다.
6. 오류가 발생하면 오류 원인, 수정 방법, 수정된 코드를 제시한다.
7. 실제 계산 결과와 AI가 생성한 해석을 명확히 구분한다.
8. 가상 데이터는 가상 데이터라고 명시한다.
9. 외부 API가 꼭 필요하지 않으면 먼저 API 없이 실행 가능한 방법을 제안한다.
10. API 키, 비밀번호, 개인정보가 코드에 노출되지 않도록 한다.
