[회사 홈페이지 제작 실습 질의문]

프로젝트 폴더명 : Company_Website_Project

1단계: 기본 HTML 구조 생성

회사 홈페이지의 기본 HTML 구조를 만들어줘.
상단에는 로고와 메뉴바, 가운데는 메인 콘텐츠 영역, 하단에는 푸터가 있도록 작성해줘.


2단계: CSS 디자인 적용

위에서 만든 HTML에 CSS를 적용해서 모던하고 심플한 디자인을 만들어줘.
색상은 회사 홈페이지에 어울리도록 파란색과 흰색 위주로 구성해줘.


3단계: 반응형 웹 구현

CSS 미디어 쿼리를 활용해서 PC, 태블릿, 모바일에서 모두 보기 좋게 반응형 디자인을 추가해줘.


4단계: 회사 소개 섹션 추가

메인 영역에 '회사 소개' 섹션을 추가해줘.
이미지와 간단한 설명이 포함되도록 HTML과 CSS를 수정해줘.


5단계: 서비스/제품 섹션 구현

회사 홈페이지에 '서비스/제품' 섹션을 추가해줘.
3개의 카드 형태로 아이콘, 제목, 설명을 넣을 수 있게 HTML과 CSS 코드를 작성해줘.


6단계: 연락처(문의하기) 폼 추가

하단 푸터 위에 '문의하기' 섹션을 추가해줘.
이름, 이메일, 메시지를 입력 받는 폼과 '보내기' 버튼을 포함하도록 작성해줘.


7단계: JavaScript 기능 추가

문의하기 폼에서 입력값이 비어 있으면 경고창을 띄우고, 입력이 올바르면 '메시지가 전송되었습니다' 라는 알림창이 뜨도록 JavaScript 코드를 작성해줘.


8단계: 네비게이션 메뉴 스크롤 기능

상단 메뉴에서 '회사소개', '서비스', '문의하기'를 클릭하면 해당 섹션으로 부드럽게 스크롤 이동하도록 JavaScript를 추가해줘.


9단계: 간단한 배포 (무료웹호스팅 서비스 / GitHub Pages 활용)

이 회사 홈페이지를 GitHub Pages에 배포할 수 있도록 README.md에 배포 방법을 설명해줘.
