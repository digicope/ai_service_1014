[Antigravity 바이브 코딩 프롬프트]

역할: 너는 파이썬 Flask 웹앱을 처음부터 완성하는 시니어 개발자다.
목표: 사용자가 입력한 문장의 감정을 Gemini로 분석하고, SQLite에 저장된 추천(음악/영화/뉴스)을 보여주는 웹 서비스를 만들어라.
실행 환경: Windows, Python 3.11, 브라우저에서 http://127.0.0.1:5000 접속.

==================================================
1) 반드시 지킬 API / 환경변수 규칙
==================================================
- 모델은 반드시 gemini-3.5-flash 만 사용한다.
- API 키는 코드에 하드코딩하지 말고 아래처럼 읽는다.

from dotenv import load_dotenv
import os
from google import genai

load_dotenv(r"C:\env\.env")
API_KEY = os.getenv("GEMINI_API_KEY")
client = genai.Client(api_key=API_KEY)

텍스트 생성 예시:
response = client.models.generate_content(
    model="gemini-3.5-flash",
    contents=prompt
)
text = response.text.strip()

==================================================
2) 기능 요구사항
==================================================
주제: 감정 분석 결과를 활용한 추천 시스템

1. 앱 시작 시 SQLite DB 파일 recommendations.db 를 생성한다.
   테이블 recommendations:
   - id INTEGER PRIMARY KEY AUTOINCREMENT
   - emotion TEXT   (happy / sad / angry / relaxed)
   - category TEXT  (music / movies / news)
   - recommendation TEXT
   테이블이 비어 있으면 아래 샘플 데이터를 INSERT 한다.
   (감정별 음악 5개, 영화 5개, 뉴스 5개)

   happy / music:
   - Pharrell Williams - Happy
   - Bobby McFerrin - Don't Worry Be Happy
   - Katrina & The Waves - Walking on Sunshine
   - Justin Timberlake - Can't Stop The Feeling!
   - Taylor Swift - Shake It Off
   happy / movies: Inside Out, The Pursuit of Happyness, La La Land, Forrest Gump, Zootopia
   happy / news: 긍정적인 세계 변화, 과학 breakthrough, 재생에너지 100%, 실업률 최저, 평화협정

   sad / music: Adele - Someone Like You, Billie Eilish - Everything I Wanted, Eric Clapton - Tears in Heaven, Sam Smith - Stay With Me, Lewis Capaldi - Someone You Loved
   sad / movies: The Green Mile, Schindler's List, Manchester by the Sea, Requiem for a Dream, Blue Valentine
   sad / news: 기아 퇴치 진전, 수해 구호, 야생동물 보호, 우울증 치료 희망, 재난 구조

   angry / music: Eminem - Lose Yourself, Linkin Park - Crawling, System of a Down - Toxicity, Rage Against the Machine - Killing in the Name, Disturbed - Down With the Sickness
   angry / movies: Joker, Falling Down, American History X, A Clockwork Orange, Fight Club
   angry / news: 도시 시위, 부패 스캔들, 정책 반발, 인권 조사, 기업 윤리 논란

   relaxed / music: Norah Jones - Come Away With Me, Coldplay - Yellow, Jack Johnson - Banana Pancakes, John Mayer - Gravity, Ed Sheeran - Thinking Out Loud
   relaxed / movies: The Secret Life of Walter Mitty, Amélie, Eat Pray Love, Midnight in Paris, Julie & Julia
   relaxed / news: 스트레스 완화법, 요가/명상 인기, 도시 녹지 확대, 디지털 디톡스, 원격근무와 정신건강

2. 감정 분석 함수 analyze_sentiment(text)
   - Gemini에게 다음 지시를 보낸다.
     "다음 문장의 감정을 분석해서 happy, sad, angry, relaxed 중에서 하나의 단어로만 말해줘"
   - 응답에서 소문자 영단어 하나만 추출해 반환한다. (설명문 금지)

3. Flask 라우트
   - GET  /            : templates/index.html 렌더
   - POST /analyze     : JSON { "text": "..." } 수신
     감정 분석 → DB에서 해당 emotion 추천 조회 → JSON 반환
     {
       "emotion": "happy",
       "recommendations": {
         "music": [...],
         "movies": [...],
         "news": [...]
       }
     }

==================================================
3) UI (templates/index.html)
==================================================
- 한국어 페이지, 제목: 감정 분석을 통한 추천 시스템
- textarea: 감정을 표현하는 문장 입력
- 버튼: [감정 분석 하기], [초기화]
- 결과 영역: 분석된 감정 + 음악/영화/뉴스 리스트
- fetch 또는 jQuery로 /analyze 호출
- 입력값이 비면 alert
