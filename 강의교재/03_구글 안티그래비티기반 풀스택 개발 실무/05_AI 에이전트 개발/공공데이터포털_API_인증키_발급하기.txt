7.1.3. 공공데이터포털 API 인증키 발급하기

실습을 시작하기 전에 공공데이터포털에서 API를 사용할 수 있도록 준비한다. AI 투자 리포트 봇은 금융위원회 지수시세정보와 주식시세정보 데이터를 호출할 예정이므로, 두 API에 대해 활용 신청을 하고 인증키와 엔드포인트 정보를 확보한다. 이 과정은 처음 한 번만 해두면 이후에는 같은 방식으로 다른 공공 API도 연결할 수 있다.

1. 공공데이터포털 회원가입

1) 웹 브라우저에서 공공데이터포털에 접속한다.
   URL: https://www.data.go.kr/index.do

2) 우측 상단의 [회원가입] 버튼을 클릭한다.

3) [일반 회원]으로 가입한다. 이름과 이메일 입력란을 적절히 채운 뒤 [가입확인] 버튼을 클릭한다.

4) 약관에 동의하고 [다음 단계]를 클릭한다.

5) 기본정보와 개인정보를 입력한 뒤 [다음 단계]를 클릭하고, 안내에 따라 본인 인증을 진행한다.

6) 회원가입이 완료되면 로그인한다.

2. 금융위원회_지수시세정보 API 활용 신청

1) 공공데이터포털 검색창에서 '금융위원회_지수시세정보'를 검색한다.

2) [오픈 API] 목록에서 '금융위원회_지수시세정보'를 찾아 클릭한다.
   - 코스피 등 주요 주가 지수를 제공하는 공공 API이다.
   - 상세 설명과 제공 데이터 항목을 확인한다.

3) API 상세 페이지에서 [활용신청] 버튼을 클릭한다.
   URL: https://www.data.go.kr/data/15094807/openapi.do

4) 신청 화면의 [활용목적]에서 '웹 사이트 개발'을 선택한다.

5) 활용목적 입력란에 '주식 웹 사이트 개발'이라고 입력한다.

6) 화면의 [동의합니다]에 체크한 뒤 [활용신청] 버튼을 클릭한다.

7) 신청이 완료되면 [마이페이지] → [데이터활용] → [Open API] → [활용신청 현황] 메뉴에서 신청 상태를 확인한다.
   - 자료의 안내에 따르면 승인된 '금융위원회_지수시세정보' 항목을 확인한다.

3. 금융위원회_지수시세정보 API 인증키 및 엔드포인트 확인

1) 활용신청 현황에서 승인된 '금융위원회_지수시세정보' 항목을 클릭한다.

2) [개발계정 상세보기] 페이지의 [서비스정보] 표를 확인한다.

3) 다음 정보를 확인하여 안전한 곳에 저장한다.
   - End Point: https://apis.data.go.kr/1160100/service/GetMarketIndexInfoService
   - 일반 인증키: 해당 페이지에 표시된 인증키

4) API 환경 또는 호출 조건에 따라 인증키 적용 방식이 다를 수 있다. 포털에 제공된 Encoding/Decoding 인증키 안내를 확인하여 사용한다.

주의:
- 인증키를 공개 문서, 공개 저장소 또는 외부에 노출하지 않는다.
- 화면에서 확인한 실제 인증키는 실습 코드에 직접 입력하기보다 환경변수로 관리한다.

4. 금융위원회_주식시세정보 API 활용 신청

1) 공공데이터포털에서 '금융위원회_주식시세정보'를 검색한다.

2) 해당 API 상세 페이지에서 [활용신청] 버튼을 클릭한다.
   URL: https://www.data.go.kr/data/15094808/openapi.do

3) 활용목적을 입력하고 약관에 동의한 뒤 신청한다.

4) [마이페이지] → [데이터활용] → [Open API] → [활용신청 현황] 메뉴에서 신청 상태를 확인한다.

5) 승인된 '금융위원회_주식시세정보' 항목을 클릭하여 [개발계정 상세보기] 페이지로 이동한다.

6) [서비스정보] 표에서 다음 정보를 확인하여 안전한 곳에 저장한다.
   - End Point: 해당 API 상세 페이지의 서비스정보 표에 표시된 주소
   - 일반 인증키: 해당 페이지에 표시된 인증키

참고:
- 제공된 이미지 자료에는 주식시세정보 API의 상세 End Point 주소가 표시되어 있지 않으므로, 실제 포털 상세 페이지에서 확인한다.

5. 인증키 및 엔드포인트 관리

두 API에서 확인한 정보를 프로젝트 환경변수 파일에 저장하여 사용한다. 예시는 다음과 같다.

FSC_INDEX_API_KEY=공공데이터포털에서_발급받은_지수시세정보_인증키
FSC_INDEX_API_URL=https://apis.data.go.kr/1160100/service/GetMarketIndexInfoService

FSC_STOCK_API_KEY=공공데이터포털에서_발급받은_주식시세정보_인증키
FSC_STOCK_API_URL=포털에서_확인한_주식시세정보_엔드포인트

실제 인증키를 예시 값 대신 입력한다. 인증키가 포함된 .env 파일은 공개 저장소에 업로드하지 않는다.

6. 신청 및 설정 완료 확인

- 공공데이터포털 회원가입 및 로그인이 완료되었는가?
- 금융위원회_지수시세정보 API 활용 신청 상태를 확인했는가?
- 금융위원회_주식시세정보 API 활용 신청 상태를 확인했는가?
- 각 API의 일반 인증키를 확인했는가?
- 각 API의 End Point를 확인했는가?
- 인증키를 안전하게 보관했는가?
