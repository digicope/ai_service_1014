# 실습 과제: TensorFlow 기반 자연환경 이미지 분류 AI 개발

## 1. 개발 목표
Intel Image Classification 데이터셋을 이용하여 이미지가 건물, 숲, 빙하, 산, 바다, 거리 중 어느 클래스에 해당하는지 분류하는 딥러닝 모델을 개발한다.
이미지 데이터 URL : https://www.kaggle.com/datasets/puneet6060/intel-image-classification

## 2. 개발 환경
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- scikit-learn

## 3. 구현 요구사항

1. 데이터셋의 폴더 구조와 이미지 개수를 확인한다.
2. 학습 데이터와 테스트 데이터를 불러온다.
3. 이미지를 150×150 크기로 변경한다.
4. 이미지 픽셀 값을 정규화한다.
5. CNN 모델을 생성한다.
   - Conv2D
   - MaxPooling2D
   - Flatten 또는 GlobalAveragePooling2D
   - Dense
6. 모델을 컴파일하고 학습한다.
7. 학습 정확도와 검증 정확도 그래프를 출력한다.
8. 테스트 데이터로 Accuracy를 계산한다.
9. 테스트 이미지 10장을 표시하고 실제 클래스와 예측 클래스를 비교한다.
10. 혼동행렬을 시각화한다.
11. 학습된 모델을 nature_classifier.keras 파일로 저장한다.

## 4. 개발 조건
- 초보자가 이해할 수 있도록 코드마다 한글 주석을 작성한다.
- 데이터셋 경로가 잘못된 경우 해결 방법을 안내한다.
- GPU가 없어도 실행할 수 있도록 모델을 간단하게 구성한다.
- 학습 시간이 길어지지 않도록 이미지 크기와 배치 크기를 적절히 설정한다.
- 실제 실행 결과를 바탕으로 정확도와 오분류 사례를 분석한다.

## 5. 최종 산출물
- 실행 가능한 Python 코드
- CNN 모델 구조
- 학습 및 검증 그래프
- 테스트 정확도와 혼동행렬
- 이미지별 예측 결과
- 자연환경 이미지 자동 분류 AI 서비스 기획 요약
