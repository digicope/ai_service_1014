[To Do List 웹 앱 구현 실습 질의문]

프로젝트 폴더명 : ToDo_List_Project

1단계: 기본 HTML 구조 만들기

HTML과 CSS를 사용해서 간단한 To Do List 기본 UI를 만들어줘.
할 일 입력 창과 추가 버튼, 할 일 목록을 표시할 영역을 포함하도록 작성해줘.

2단계: 날짜 표시
할 일 입력 창 위에 오늘 날짜가 표시되고 날짜를 변경할 수 있게 해줘.

3단계: 할 일 추가 및 삭제 기능 구현
JavaScript로 입력창에 텍스트 입력 후 '추가' 버튼 클릭 시 할 일이 목록에 추가되고, 각 항목에 '삭제' 버튼을 눌러 제거할 수 있도록 코드 작성해줘.

4단계: 완료 표시 기능 구현 
할 일 항목을 클릭하면 줄이 그어지면서 '완료 처리'된 것처럼 표시되는 기능을 JavaScript로 추가해줘.

5단계: CSS로 디자인 개선
CSS를 이용해서 To Do List 앱을 좀 더 깔끔하게 디자인해줘. 삭제 버튼을 아이콘으로 바꿔주고
버튼에 hover 효과를 주고, 완료된 항목은 회색 글자와 취소선이 표시되도록 수정해줘.

6단계: 로컬 스토리지에 데이터 저장
할 일을 추가할 때 날짜와 함께 LocalStorage에 저장하고, 삭제 시 LocalStorage에서도 제거되며, 새로 고침이나 처음 시작 시 LocalStorage에서 불러와 목록을 표시하도록 코드 수정해줘.

7단계: 전체 삭제 및 필터 기능 추가
'전체 삭제' 버튼을 추가해 모든 할 일을 한 번에 지울 수 있고, '전체/완료/미완료' 버튼으로 목록을 필터링할 수 있도록 코드를 수정해줘.

8단계: 캘린더 기능 추가
날짜 출력 아래에 해당 월의 캘린더가 출력되고 오늘 날짜 표시와 선택한 날짜를 표시를 해주도록 코드를 수정해줘.

9단계: 할 일 갯수 표시 기능 추가
캘린더에서 할 일이 추가되어 있는 날짜에 할 일이 몇 개인지를 표시해 주도록 코드를 수정해줘.

10단계: 제목 수정
맨 위 'To Do List' 제목을 한글로 더 멋진 제목으로 변경하고 세로 폭도 적당하게 줄여주고 제목 옆 아이콘도 더 세련되게 붙여줘.
아이콘을 제목 좌측으로 배치하고 제목 출력 영역의 세로 크기를  절반으로 줄여줘.
