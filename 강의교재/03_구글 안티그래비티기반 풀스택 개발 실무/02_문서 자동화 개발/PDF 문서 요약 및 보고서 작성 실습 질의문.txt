[PDF 문서 요약 및 보고서 작성 실습 질의문]

프로젝트 폴더명 : PDF_Summary_Project


1단계: PDF 불러오기
현재 폴더안에 들어 있는 Tech-Report-Generative-AI.pdf 이름의 PDF 파일을 불러오고 페이지별 텍스트를 추출하여 저장하는 파이썬 코드를 만들어줘.

<모듈설치>
pip install PyPDF2 pdfplumber python-docx reportlab python-pptx pandas

2단계: 텍스트 전처리
추출한 전체 텍스트를 불필요한 줄바꿈, 공백 등을 제거하여 새로운 파일에 저장하는 전처리 코드를 추가해줘.

3단계: 요약 생성
전처리 된 전체 텍스트를 기반으로 핵심 내용을 5문장 이내로 요약해줘.

4단계: 목차 및 주제별 요약
전처리 된 텍스트 내용을 3~5개의 주요 주제로 구분하고, 각 주제별로 요약 문단을 작성해줘.

5단계: 보고서 자동 생성 (Word)
요약된 내용을 기반으로 ‘보고서(Report)’ 형식의 문서를 자동으로 생성해서 report.docx 파일로 저장해줘. 

6단계: 시각적 요소 포함
보고서에 제목, 소제목, 불릿포인트 요약을 포함하고 표나 리스트 형식으로 정리된 보고서 구조를 갖추도록 수정해줘.

7단계: 최종 PDF 저장
작성된 보고서를 Word(docx)뿐 아니라 PDF 파일로도 저장해줘.

8단계: PPT 자동 생성
요약된 내용을 기반으로 PPT 파일(pptx)을 만들어줘.  각 주요 주제를 슬라이드 제목으로 하고, 해당 요약 내용을 불릿포인트로 정리해서 슬라이드에 넣어줘. 


<추가 기능 구현 (옵션)>
- 키워드 추출 기능 추가
불러온 PDF에서 주요 키워드 10개를 TF-IDF 또는 KeyBERT 기법을 활용하여 추출하는 파이썬 코드를 작성해줘.

- 요약 + 키워드 시각화 (WordCloud)
추출한 키워드를 WordCloud 형태의 이미지로 생성하고, 보고서(docx)와 PPT 슬라이드에 함께 삽입하는 코드를 만들어줘.

- 페이지별 요약 기능
PDF를 페이지 단위로 나누어 각 페이지마다 요약 결과를 출력하고, 이를 별도의 슬라이드(PPT)로 정리하는 코드를 작성해줘.

- 다국어 번역 기능
PDF 요약 결과를 한국어와 영어 두 가지 버전으로 생성해서 보고서(docx)와 PPT 슬라이드에 각각 추가하는 코드를 작성해줘.

- 차트 삽입 기능
PDF에서 표 형식 데이터를 추출하여 pandas DataFrame으로 정리하고, matplotlib을 이용해 그래프를 생성한 후 PPT 슬라이드에 추가하는 코드를 작성해줘.

- 질의응답(Q&A) 기능 추가
PDF 내용을 기반으로 사용자가 질문을 입력하면 관련된 답변을 생성하는 간단한 Q&A 챗봇 기능을 추가하는 코드를 작성해줘. (OpenAI API 활용)

- 통합 대시보드 생성
Streamlit을 사용해서 PDF 파일 업로드 → 요약 → 키워드 추출 → 보고서/PPT 생성 과정을 한 화면에서 실행할 수 있는 대시보드 앱을 만들어줘.
