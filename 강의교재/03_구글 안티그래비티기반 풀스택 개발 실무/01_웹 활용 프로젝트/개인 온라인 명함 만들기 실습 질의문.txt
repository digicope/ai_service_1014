[개인 온라인 명함 만들기 실습 질의문]

프로젝트 폴더명 : Name_Card_Project

1단계: 기본 구조 만들기
 
HTML과 CSS를 사용해서  ‘개인 온라인 명함’ 기본 구조를 만들어줘. 이름, 직업, 연락처, 이메일, 한 줄 소개가 들어가도록 해줘.


2단계: 프로필 사진 추가

명함을 화면 가운데 정렬하고, 카드 스타일(흰 배경, 그림자, 둥근 모서리)로 꾸며줘. 그리고 명함 상단에 프로필 사진이 들어가도록 수정해줘. 사진은 원형으로 보이게 해줘.


3단계: 개인 사진 추가

폴더에 복사해 놓은 person.jpg 사진을  프로필 사진으로 출력하도록 수정해줘.


4단계: 반응형 디자인 적용
 
스마트폰 화면에서도 잘 보이도록 반응형 CSS를 적용해줘. 작은 화면에서는 명함 카드 크기가 자동으로 줄어들도록 해줘.


5단계: 배경 꾸미기
 
명함 배경에 그라데이션 색상을 적용해줘. 위쪽은 파랑, 아래쪽은 흰색으로 자연스럽게 연결되도록 CSS를 수정해줘.


6단계: 다크 모드 추가

명함 내부 색상을 좀더 세련되게 바꿔주고 버튼을 클릭하면 다크 모드(검정 배경 + 흰색 글자)로 전환되는 JavaScript 기능을 추가해줘.


7단계: 색상 수정

여전히 배경과 명함 색상이 세련되지 않아. 배경은 약간 어두운 색상으로 명함 안쪽은 밝은 색상으로 바꿔줘.


8단계: Portfolio 화면 연결
 
Portfolio 버튼을 클릭하면 열리는 portfolio.html을 만들어줘.
프로젝트 2~3개를 카드 형식으로 보여주고, 각 카드에는 이미지, 제목, 설명, GitHub 또는 Demo 링크 버튼을 넣어줘.
레이아웃은 가운데 정렬하고 카드에는 흰 배경, 그림자, 둥근 모서리 스타일을 적용해줘.”

(배경 화면을 파란색 계열로 다시 바꿔줘.)

9단계: 이메일 전송 기능 추가
하단에 Contacts 버튼을 추가하고, 버튼을 누르면 이름·이메일·메시지를 입력할 수 있는 메일 폼이 뜨도록 해줘.
폼에서 ‘보내기’를 클릭하면 send_mail.php가 실행되어 PHP mail() 함수로 메일이 전송되도록 수정해줘.
메일 수신 주소는 digicope@aicore.co.kr 이야
(자신의 이메일 주소로 변경해서 입력한다)

10단계: 버튼 위치 수정
Contacts 버튼을 메인 페이지의 Portpolio 버튼 옆에 만들어주고  이 버튼을 누르면 바로 메일 폼이 뜨도록 코드 수정해줘.


- 그 외 자신에게 필요한 기능이 있으면 추가로  구현해본다
