# 실습 과제: 공공데이터 API 연동 및 AI 금융 데이터 분석 웹 애플리케이션 개발

## 1. 프로젝트 개요

Google Antigravity IDE를 활용하여 공공데이터포털에서 제공하는 Open API를 연동하고, API로 수집한 금융 데이터를 가공한 후 Google Gemini를 활용해 분석하는 파이썬 기반웹 애플리케이션을 개발한다.

처리 흐름은 다음과 같다.

API 인증키 설정 → 공공데이터 API 호출 → JSON 데이터 수집 → 데이터 전처리 → 데이터 집계 및 분석 → Gemini AI 분석 → 결과 출력

## 2. 개발 환경

- 개발 도구: Google Antigravity
- 프로그래밍 언어: Python
- 웹 프레임워크: Streamlit
- HTTP 통신: requests
- 데이터 처리: pandas
- AI 모델: Google Gemini API
- 환경변수 관리: python-dotenv

## 3. 데이터 수집

공공데이터포털(data.go.kr)에서 제공하는 금융 관련  API를 활용한다.

실습 대상 데이터는 금융위원회의 주식시세정보 또는 주식시세 관련 공공데이터로 설정한다.

단, API 명세에서 제공하는 실제 서비스명, 엔드포인트, 필수 파라미터 및 응답 구조를 먼저 확인한 후 구현한다. 확인되지 않은 API 주소나 파라미터를 임의로 작성하지 않는다.

API 인증키가 아직 발급되지 않은 경우에는 샘플 JSON 데이터를 이용해 나머지 기능을 먼저 구현하고, 인증키 발급 후 실제 API와 연동할 수 있도록 설계한다.

## 4. 주요 기능

### 기능 1. API 인증정보 관리

- API 인증키를 환경변수로 관리한다.
- 프로젝트 루트에 .env 파일을 사용한다.
- .env 파일을 Git에 업로드하지 않도록 .gitignore를 설정한다.
- 인증키가 없으면 사용자에게 설정 방법을 안내한다.
- 인증키를 소스 코드에 직접 입력하지 않는다.

환경변수 예시:

DATA_API_KEY=발급받은_API_인증키
GEMINI_API_KEY=발급받은_GEMINI_API_키

### 기능 2. 공공데이터 API 호출

- requests 라이브러리로 API를 호출한다.
- HTTP 상태 코드와 API 응답 오류를 처리한다.
- JSON 응답을 파싱한다.
- 페이지 번호와 조회 건수를 설정할 수 있도록 한다.
- API 호출 실패 시 원인과 해결 방법을 화면에 표시한다.
- API 응답 원본을 확인할 수 있는 디버깅 기능을 제공한다.

### 기능 3. 데이터 전처리

- JSON 데이터를 pandas DataFrame으로 변환한다.
- 컬럼명과 데이터 형식을 정리한다.
- 결측치 및 중복 데이터를 확인한다.
- 숫자형 데이터는 적절한 숫자 자료형으로 변환한다.
- 날짜 데이터는 datetime 형식으로 변환한다.
- 전처리 전후의 데이터 건수를 비교하여 출력한다.
- 데이터가 없거나 예상한 컬럼이 존재하지 않을 경우 예외를 처리한다.

### 기능 4. 데이터 분석 및 시각화

- 수집 데이터의 전체 건수를 표시한다.
- 주요 컬럼의 통계 요약을 제공한다.
- 조회 가능한 날짜 및 종목 등의 조건으로 데이터를 필터링한다.
- 분석 결과를 표와 그래프로 출력한다.
- 실제 API에서 제공하지 않는 지표는 임의로 생성하지 않는다.

### 기능 5. Gemini AI 분석

Google Gemini API를 사용하여 수집된 금융 데이터를 요약하고 분석한다.

- 데이터의 주요 특징을 자연어로 요약한다.
- 데이터에서 확인되는 변화와 패턴을 설명한다.
- 분석에 사용한 데이터의 범위와 기준을 명시한다.
- 데이터에 없는 사실이나 수치를 만들어내지 않도록 한다.
- 투자 매수·매도 추천이 아닌 데이터 설명과 정보 제공을 목적으로 한다.
- API 호출 오류와 응답 지연을 처리한다.
- 대량의 데이터를 그대로 전송하지 말고 통계 요약 및 일부 데이터만 전달한다.

### 기능 6. Streamlit 웹 화면

다음 화면 요소를 구현한다.

1. 프로젝트 제목과 서비스 설명
2. API 연결 상태 표시
3. 조회 조건 입력 영역
4. 데이터 수집 실행 버튼
5. 원본 데이터 및 전처리 데이터 확인
6. 데이터 통계와 시각화
7. Gemini AI 분석 실행 버튼
8. AI 분석 결과 출력 영역
9. 오류 및 실행 상태 메시지

## 5. 프로젝트 파일 구조

다음 구조로 파일을 생성한다.

public_finance_agent/
├── app.py
├── api_client.py
├── data_processor.py
├── ai_analyzer.py
├── requirements.txt
├── .env
└── README.md

각 파일의 역할은 다음과 같다.

- app.py: Streamlit 웹 애플리케이션 실행 및 화면 구성
- api_client.py: 공공데이터 API 호출 및 응답 처리
- data_processor.py: 데이터 전처리, 집계 및 통계 계산
- ai_analyzer.py: Gemini API를 이용한 데이터 요약 및 분석
- requirements.txt: 필요한 Python 라이브러리 목록
- .env: 환경변수 설정 
- .gitignore: 인증정보 및 불필요한 파일 제외
- README.md: 설치, 실행 및 API 인증키 설정 안내

## 6. 구현 및 검증 순서

다음 순서대로 단계적으로 개발한다.

1단계: 프로젝트 폴더 및 가상환경 구성

2단계: 필요한 라이브러리 설치

3단계: 샘플 JSON 데이터로 전처리 기능 구현

4단계: 공공데이터 API 호출 기능 구현

5단계: 전처리 및 데이터 분석 기능 구현

6단계: Gemini API 연동

7단계: Streamlit 화면 구성

8단계: 전체 기능 통합 및 테스트

9단계: README.md 작성 및 실행 방법 검증

각 단계를 완료할 때마다 실행하여 오류를 수정한 다음 다음 단계로 진행한다.

## 7. 테스트 및 완료 조건

- 샘플 데이터로 전체 기능을 실행할 수 있어야 한다.
- 유효한 인증키를 설정하면 실제 API 호출을 수행할 수 있어야 한다.
- 인증키 누락, API 오류, 빈 데이터, 결측치 등의 상황을 처리해야 한다.
- 전처리 결과와 분석 결과를 웹 화면에서 확인할 수 있어야 한다.
- Gemini API를 통해 데이터 요약 결과를 출력해야 한다.
- 인증키가 코드나 로그에 노출되지 않아야 한다.
- README.md만으로 다른 사용자가 프로젝트를 설치하고 실행할 수 있어야 한다.

## 8. 개발 지침

Google Antigravity의 AI 코딩 기능을 활용하되 모든 코드를 한 번에 생성하지 않는다.

먼저 프로젝트 구조와 구현 계획을 제시하고, 각 파일을 순차적으로 작성한다. 각 단계에서 실행 결과를 확인하고 오류가 발생하면 원인을 분석하여 수정한다.

실제 API 명세를 확인할 수 없는 경우에는 API를 임의로 추정하지 말고, 샘플 데이터 기반으로 구현한 뒤 필요한 API 정보를 사용자에게 요청한다.

최종적으로 실행 가능한 Python 기반 공공데이터 API 연동 및 AI 분석 웹 애플리케이션을 완성한다.
