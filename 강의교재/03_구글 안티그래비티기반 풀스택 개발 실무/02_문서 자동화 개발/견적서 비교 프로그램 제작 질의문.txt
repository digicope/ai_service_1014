[견적서 비교 프로그램 제작 실습 질의문]

프로젝트 폴더명 : Estimate_Comparison_Project

1단계: 견적서 불러오기
현재 폴더안에 들어 있는 파일을 불러와서 업체명, 품목, 수량, 단가, 총액을 DataFrame 으로 출력해주는
파이썬 코드를 만들어줘. 엑셀 하단의 제품 특장점, 납품 조건, A/S 안내도 함께 출력하게 해줘.

<모듈설치>
pip install pandas, openpyxl, tabulate, matplotlib


2단계: 여러 파일 합치기

폴더 안의 모든 견적서 파일을 순회해서 한 번에 불러오고, 항목 데이터는 하나의 DataFrame으로 합치고, 업체별 상세 조건(특장점, 납품 조건, A/S)은 별도의 DataFrame으로 정리해줘.

3단계: 비교표 생성

합쳐진 DataFrame을 사용해서 품목별 단가 비교표와 총액 비교표를 PivotTable 형태로 만들어줘.

4단계: 최저가 표시

각 품목별로 최저가와 해당 업체명을 나타내는 컬럼을 비교표에 추가해줘.

5단계: 업체별 상세 조건 요약

업체별로 제품 특장점, 납품 조건, A/S 안내를 한눈에 볼 수 있도록 요약표를 만들어줘.

6단계: 비교표 출력

단가 비교표, 총액 비교표, 업체별 상세 조건 요약표를 보기 좋게 출력해줘.

7단계: 파일 저장

비교 결과를 비교결과.xlsx 파일로 저장하고, 단가 비교 결과는 단가비교.csv로도 저장해줘.

(Cursor에 Rainbow CSV 익스텐션 설치하고 CSV 파일 확인)

8단계: 시각화

업체별 총액 합계를 집계해서 막대그래프로 출력하고 totals_by_vendor.png 파일로 저장해줘.

9단계: 실행부 완성

main.py에 실행부를 작성해서 위 기능들이 순서대로 동작하도록 완성해줘.
