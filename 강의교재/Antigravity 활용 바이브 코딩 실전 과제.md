- 바이브 코딩을 활용한 웹 애플리케이션 개발
- CRUD 기능 구현
- 데이터 저장 및 검색 기능 구현
- 대시보드 및 데이터 시각화
- 사용자 중심 UI/UX 설계

## 2.3 주요 구현 기능

| 구분 | 구현 내용 |
|---|---|
| 대시보드 | 전체 지원 건수, 서류 합격, 면접, 최종 합격 통계 |

| 검색 | 기업명 및 직무 검색 |
| 필터 | 지원 중, 서류 합격, 면접, 불합격 |
| 시각화 | 지원 현황 및 월별 지원 건수 차트 |
| 데이터 저장 | SQLite 또는 LocalStorage |

## 2.4 세부 실습 요구사항

1. 반응형 웹 디자인을 적용한다.

3. 초기 실행 시 10건 이상의 샘플 데이터를 제공한다.
4. 데이터 등록, 조회, 수정, 삭제 기능을 구현한다.
5. 기업명 및 직무별 검색 기능을 구현한다.
6. 지원 현황을 차트로 시각화한다.
7. 데이터를 저장하고 다시 실행해도 유지되도록 한다.

# 3. 실전 과제 2 : Gemini API 기반 AI 취업 컨설팅 챗봇 개발

## 3.1 과제 개요

사용자의 취업 관련 질문에 AI가 답변하는 취업 컨설팅 챗봇을 개발한다.

Gemini API를 활용하여 취업 준비, 자기소개서 작성, 면접 준비 및 직무 선택에 대한 상담을 제공한다.

## 3.2 실습 목표

- 생성형 AI API 활용
- Gemini API 연동
- 시스템 프롬프트 설계
- 멀티턴 대화 기능 구현
- AI 챗봇 UI 개발

## 3.3 주요 구현 기능

| 구분 | 구현 내용 |
|---|---|
| AI 대화 | Gemini API 기반 질문 및 답변 |
| 취업 상담 | 취업 준비, 직무 선택, 취업 전략 |
| 자기소개서 | 자기소개서 문장 개선 및 피드백 |
| 면접 준비 | 예상 면접 질문 및 답변 예시 |
| 직무 분석 | 직무별 필요 역량과 기술 분석 |
| 대화 이력 | 이전 대화 내용 확인 |
| 프롬프트 | 취업 컨설턴트 역할 및 응답 형식 지정 |

## 3.4 세부 실습 요구사항

1. Gemini API를 연동한다.
2. 사용자의 질문을 입력받고 AI 응답을 출력한다.
3. 이전 대화 내용을 기억하는 멀티턴 대화 기능을 구현한다.
4. 취업 관련 질문에 특화된 시스템 프롬프트를 설계한다.
5. 대화 초기화 및 추천 질문 기능을 제공한다.
6. API Key는 .env 파일로 관리한다.
7. API 오류 및 네트워크 오류를 처리한다.

## 3.5 Antigravity 실습 프롬프트

### [실전 과제] AI 취업 컨설팅 챗봇 개발

Google Antigravity를 사용하여 Gemini API 기반 AI 취업 컨설팅 챗봇을 개발해줘.

1. 과제 목표

취업 준비생에게 취업 정보, 자기소개서 작성, 면접 준비 및 직무 선택에 관한 상담을 제공하는 AI 챗봇을 제작한다.

2. 개발 환경

- Python 3.12 이상
- Streamlit 또는 Flask
- Google Gemini API
- python-dotenv
- .env 환경변수 관리

3. 주요 기능

① AI 취업 상담
- 취업 준비 방법
- 직무 및 기업 선택
- 취업 전략 수립

② 자기소개서 컨설팅
- 자기소개서 문장 개선
- 문장 및 내용 피드백
- 항목별 작성 방법 안내

③ 면접 컨설팅
- 직무별 예상 면접 질문 생성
- 답변 예시 제공
- 답변 개선 방향 제안

④ 직무 분석
- 직무별 주요 업무 설명
- 필요 기술 및 역량 분석
- 관련 자격증 및 학습 방향 제안

⑤ 대화 관리
- 이전 대화 문맥 유지
- 대화 초기화
- 추천 질문 버튼 제공

4. 시스템 프롬프트

AI는 전문 취업 컨설턴트 역할을 수행한다.

- 친절하고 구체적으로 답변한다.
- 초보 취업 준비생도 이해할 수 있도록 설명한다.
- 답변은 제목, 핵심 내용, 실행 방법으로 구분한다.
- 근거가 부족한 정보는 사실처럼 단정하지 않는다.
- 자기소개서 작성 시 사용자가 제공하지 않은 경력이나 경험을 임의로 만들어내지 않는다.

5. 화면 구성
- 왼쪽: 상담 주제 및 추천 질문
- 중앙: 채팅 대화 영역
- 하단: 질문 입력창 및 전송 버튼
- 대화 초기화 버튼
- AI 답변 로딩 표시

6. 개발 및 테스트
- API Key는 .env 파일에서 불러온다.
- .env 파일은 Git에 업로드되지 않도록 설정한다.
- 필요한 패키지를 requirements.txt에 작성한다.
- API 오류 및 네트워크 오류를 처리한다.
- 실행 방법을 README.md에 작성한다.

최종적으로 실제 취업 준비생이 활용할 수 있는 AI 취업 컨설팅 챗봇을 완성해줘.

## 3.6 추가 도전 과제

- PDF 자기소개서 업로드 및 분석
- 직무별 맞춤 면접 질문 생성
- 면접관 역할을 수행하는 모의 면접 기능
- 답변 평가 및 점수 제공

# 4. 실전 과제 3 : AI Agent 기반 채용공고 분석 및 취업 전략 수립

## 4.1 과제 개요

사용자가 자신의 경력 및 보유 기술을 입력하면 채용공고를 분석하고 적합한 기업과 직무를 추천하는 AI Agent를 개발한다.

일반적인 챗봇과 달리 사용자의 요청을 여러 단계로 분해하고, 필요한 도구(Tool)를 호출하여 결과를 종합하는 것이 핵심이다.

## 4.2 실습 목표

- AI Agent의 개념 및 동작 원리 이해
- Gemini API 기반 Agent 구현
- Tool Calling 기능 구현
- 데이터 분석 및 적합도 계산
- 여러 작업을 연결하는 자동화 서비스 개발

## 4.3 주요 구현 기능

| 구분 | 구현 내용 |
|---|---|
| 사용자 정보 | 학력, 전공, 경력, 기술, 자격증 입력 |
| 채용공고 검색 | CSV 기반 채용공고 데이터 조회 |
| 공고 분석 | 기업별 직무 및 요구 역량 분석 |
| 적합도 분석 | 사용자 역량과 채용 조건 비교 |
| 부족 역량 분석 | 보유 기술과 요구 기술의 차이 분석 |
| 취업 전략 | 학습 방향 및 취업 준비 계획 생성 |
| 결과 보고서 | 추천 기업 및 직무 분석 리포트 생성 |

## 4.4 AI Agent 및 Tool 구성

Tool 1. 채용공고 검색
- 사용자의 희망 직무와 관련된 공고 검색
- 기술 및 경력 조건에 따른 필터링

Tool 2. 직무 역량 분석
- 채용공고의 필수 기술과 우대 기술 분석
- 직무 수행에 필요한 핵심 역량 정리

Tool 3. 직무 적합도 계산
- 사용자 보유 기술과 채용공고 요구 기술 비교
- 기술 일치율 계산
- 적합도 점수와 평가 근거 제공

Tool 4. 부족 역량 분석
- 사용자에게 부족한 기술과 역량 도출
- 우선적으로 학습해야 할 항목 추천

Tool 5. 취업 전략 생성
- 추천 기업 및 직무 정리
- 부족 역량에 대한 학습 계획 생성
- 취업 준비 로드맵 제시

## 4.5 Agent 동작 구조

① 사용자 정보 입력
- 학력, 전공, 경력, 기술, 자격증, 희망 직무

② AI Agent
- 사용자 요청 분석
- 작업 계획 수립

③ Tool 실행
- 채용공고 검색
- 직무 역량 분석
- 적합도 계산
- 부족 역량 분석
- 취업 전략 생성

④ 결과 통합
- 기업별 적합도 비교
- 추천 직무 선정
- 취업 준비 전략 생성

⑤ 최종 보고서
- 추천 기업
- 직무 적합도
- 부족 역량
- 학습 계획

## 4.6 세부 실습 요구사항

1. Gemini API를 활용한다.
2. Agent가 사용할 Tool을 4개 이상 구현한다.
3. 채용공고 데이터는 CSV 파일로 제공한다.
4. 채용공고 데이터는 20건 이상 구성한다.
5. 사용자 입력과 채용공고 데이터를 비교한다.
6. 적합도 분석 결과를 수치 및 근거와 함께 제시한다.
7. 분석 결과를 웹 화면에 출력한다.
8. 최종 결과를 PDF 또는 HTML 보고서로 저장한다.
9. Agent가 실제로 Tool을 호출하는지 확인한다.

- 우대 기술
- 경력 조건
- 학력 조건

채용공고 데이터는 CSV 파일로 구성하고 20건 이상의 샘플 데이터를 생성한다.

4. AI Agent 및 Tool 구현

Tool 1. 채용공고 검색
- 사용자의 희망 직무와 관련된 공고 검색
- 기술 및 경력 조건에 따른 필터링

Tool 2. 직무 역량 분석
- 채용공고의 필수 기술과 우대 기술 분석
- 직무 수행에 필요한 핵심 역량 정리

Tool 3. 직무 적합도 계산
- 사용자 보유 기술과 채용공고 요구 기술 비교
- 기술 일치율 계산
- 적합도 점수와 평가 근거 제공

Tool 4. 부족 역량 분석
- 사용자에게 부족한 기술과 역량 도출
- 우선적으로 학습해야 할 항목 추천

Tool 5. 취업 전략 생성
- 추천 기업 및 직무 정리
- 부족 역량에 대한 학습 계획 생성
- 취업 준비 로드맵 제시

5. Agent 동작 방식

① 사용자 정보를 입력받는다.
② AI Agent가 사용자 요청을 분석한다.
③ 채용공고 검색 Tool을 실행한다.
④ 직무 역량 및 적합도를 분석한다.
⑤ 부족 역량 분석 Tool을 실행한다.
⑥ 취업 전략 생성 Tool을 실행한다.
⑦ 전체 결과를 종합하여 최종 보고서를 생성한다.

6. 화면 구성
- 사용자 정보 입력 화면
- 채용공고 검색 결과
- 기업별 적합도 점수
- 부족 역량 분석
- 취업 전략 및 학습 로드맵
- 최종 분석 보고서 다운로드

7. 개발 및 테스트
- 각 Tool의 실행 결과를 확인할 수 있도록 한다.
- Agent가 실제로 Tool을 호출하는지 확인한다.
- API 오류 및 예외 상황을 처리한다.
- 분석 결과는 실제 계산 결과와 AI의 해석을 구분한다.
- 실행 방법과 과제 실행 환경을 README.md에 작성한다.

최종적으로 취업 준비생이 자신의 역량에 맞는 기업을 찾고 취업 전략을 수립할 수 있는 AI Agent 서비스를 완성해줘.

# 9. 실습 시 유의사항

1. Antigravity가 생성한 코드를 무조건 신뢰하지 않고 실행 결과를 확인한다.
2. 오류가 발생하면 오류 메시지를 분석하고 프롬프트를 수정하여 해결한다.
3. API Key 등 중요한 인증정보는 소스 코드에 직접 작성하지 않는다.
4. 실제 개인정보나 민감한 이력서 정보를 실습 데이터로 사용하지 않는다.
5. AI가 생성한 분석 결과와 실제 데이터에 근거한 계산 결과를 구분한다.
6. 실습을 완료한 후 README.md에 설치 및 실행 방법을 작성한다.
7. Git을 활용하여 소스 코드와 변경 이력을 관리한다.
