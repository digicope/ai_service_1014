[유튜브 스크립트 요약 실습 질의문]

프로젝트 폴더명 : Youtube_Script_Project


1단계: 기본 스크립트 불러오기
youtube-transcript-api 를 사용하여 유튜브 영상 자막을 가져오는 파이썬 코드 만들어줘.
영상 주소는 https://www.youtube.com/watch?v=ZcmYHh1TgVc

<모듈설치>
pip install youtube-transcript-api

2단계: API 버전 오류 수정
소스 코드 버전에 따른 오류 수정해줘.

3단계: 전체 요약
불러온 유튜브 스크립트를 5문장 이내로 요약해줘.

4단계: 핵심 주제 뽑기
이 스크립트에서 핵심 주제를 3가지로 정리해줘.

5단계: 시간 구간별 요약
유튜브 스크립트를 5분 단위로 나누어 각 구간의 요약을 작성해줘.

6단계: Q&A 형태 변환
스크립트 내용을 바탕으로 '자주 묻는 질문과 답변(FAQ)' 형식으로 변환해줘.

7단계: 컨텐츠로 활용하기
이 스크립트 요약을 블로그용 글로 다듬어줘.
(짧은 제목, 서론, 본문 요약, 결론 포함)

- 추가 기능
이 스크립트에서 자주 등장하는 핵심 키워드 10개를 뽑아줘.
이 스크립트 전반의 화자의 감정(긍정/부정/중립)을 분석해줘. 근거가 되는 문장도 함께 제시해줘.
이 스크립트를 바탕으로 학생용 요약 노트를 만들어줘.(핵심 요점 bullet point 형식, 쉬운 설명 포함)
이 스크립트의 주요 내용을 바탕으로 발표자에게 물어볼 수 있는 인터뷰 질문 5개를 만들어줘.
이 스크립트의 주요 내용을 인공지능 최신 동향(2025년 기준)과 비교해줘.
이 스크립트의 요약을 한글과 영어로 함께 작성해줘.
이 스크립트 내용을 바탕으로 4지선다형 객관식 퀴즈 5문제를 만들어줘.(보기는 (a), (b), (c), (d)로 표기해줘)

유튜브 영상 링크를 입력하면  스크립트를 추출해서 위와 같은 분석 작업을 수행해서 자동으로 새로운
md 파일로 저장하는 GUI 앱을 만들어줘
