# 실습 1: 고객 구매 데이터 생성 및 탐색

너는 데이터 분석 전문 파이썬 개발자이다.

온라인 쇼핑몰의 고객 구매 데이터 전처리 실습을 위한 파이썬 프로그램을 작성해줘.

요구사항:
1. pandas를 사용한다.
2. 다음 컬럼을 포함하는 가상의 고객 구매 데이터 100건을 생성한다.
   - order_id: 주문번호
   - customer_name: 고객명
   - age: 나이
   - purchase_amount: 구매 금액
   - order_date: 주문일
   - category: 상품 카테고리
3. 일부 행에는 결측치, 중복 데이터, 잘못된 날짜, 비정상적인 나이와 구매 금액을 의도적으로 포함한다.
4. 데이터를 customer_orders.csv 파일로 저장한다.
5. CSV 파일을 다시 읽어 데이터의 행과 열 개수, 컬럼명, 자료형, 상위 5개 행, 기초 통계량을 출력한다.
6. 코드를 초보자도 이해할 수 있도록 한글 주석을 작성한다.
7. 실행 방법과 필요한 라이브러리를 설명한다.

파일명은 step1_data_generation.py로 작성해줘.

# 실습 2: 데이터 품질 진단 프로그램

앞서 생성한 customer_orders.csv 파일을 분석하는 파이썬 코드를 작성해줘.

요구사항:
1. pandas로 CSV 파일을 불러온다.
2. 컬럼별 결측치 개수와 비율을 계산한다.
3. 중복 행의 개수와 중복 주문번호를 확인한다.
4. 컬럼별 자료형을 출력한다.
5. 나이가 0보다 작거나 120보다 큰 행을 탐지한다.
6. 구매 금액이 음수인 행을 탐지한다.
7. 날짜 형식이 잘못된 행을 탐지한다.
8. 구매 금액에 숫자가 아닌 문자가 포함된 행을 탐지한다.
9. 각 문제를 표 형태로 출력한다.
10. 진단 결과를 preprocessing_diagnosis.csv로 저장한다.

원본 데이터는 수정하지 않는다.
각 진단 로직에 한글 주석을 작성하고 초보자가 이해할 수 있도록 설명해줘.

파일명은 step2_diagnosis.py로 작성해줘.

# 실습 3: 고객 구매 데이터 정제

customer_orders.csv를 불러와 데이터 전처리를 수행하는 파이썬 프로그램을 작성해줘.

요구사항:
1. 고객명과 상품 카테고리의 앞뒤 공백을 제거한다.
2. 완전히 동일한 중복 행을 제거한다.
3. 주문번호가 중복된 경우에는 주문번호와 행 내용을 확인하고, 임의로 삭제하지 말고 중복 처리 정책을 명시한다.
4. 나이와 구매 금액을 숫자형으로 변환한다. 구매 금액에 포함된 쉼표, 원 등의 문자를 처리한다.
5. 날짜를 datetime 형식으로 변환하고 잘못된 날짜는 결측치로 처리한다.
6. 나이가 0보다 작거나 120보다 큰 값은 비정상값으로 표시하고 결측치로 처리한다.
7. 음수 구매 금액은 자동 삭제하지 말고 별도 오류 데이터로 분리한다.
8. 결측치 처리 정책을 변수별로 구분한다. 나이의 중앙값 대체, 날짜의 결측 유지, 구매 금액의 처리 보류 등 선택한 방법과 이유를 설명한다.
9. 정제 전후의 행 수, 결측치 수, 중복 행 수를 비교한다.
10. 정제 결과를 cleaned_data.csv로 저장하고 오류 데이터는 rejected_data.csv로 저장한다.
11. 원본 데이터는 덮어쓰지 않는다.

각 전처리 단계에 한글 주석을 작성하고, 데이터가 임의로 손실되지 않도록 처리 전후 검증 코드를 포함해줘.

파일명은 step3_cleaning.py로 작성해줘.

# 실습 4: 분석용 데이터셋 생성

cleaned_data.csv 파일을 이용해 분석용 파생 변수를 생성하는 파이썬 코드를 작성해줘.

요구사항:
1. 구매 금액을 기준으로 고객 구매 등급을 분류한다.
   - 30,000원 미만: 일반
   - 30,000원 이상 70,000원 미만: 우수
   - 70,000원 이상: VIP
2. 주문일에서 연도, 월, 요일을 추출한다.
3. 카테고리별 주문 건수와 구매 금액 합계를 계산한다.
4. 월별 구매 금액 합계를 계산한다.
5. 나이 구간을 20대, 30대, 40대, 기타로 분류한다.
6. 집계 과정에서 결측치가 결과에 어떤 영향을 미치는지 설명한다.
7. 분석 결과를 각각 CSV 파일로 저장한다.
8. 막대그래프와 월별 구매 추이 그래프를 생성한다.
9. Matplotlib 그래프의 제목과 축 이름은 한글로 작성한다.

파일명은 step4_feature_engineering.py로 작성해줘.

# 실습 5: 통합 데이터 전처리 애플리케이션

앞서 수행한 데이터 생성, 품질 진단, 정제, 파생 변수 생성 기능을 하나의 파이썬 프로그램으로 통합해줘.

요구사항:
1. 입력 CSV 파일 경로를 지정할 수 있게 한다.
2. 데이터 품질을 자동 진단한다.
3. 결측치, 중복 데이터, 자료형 오류, 이상값을 처리한다.
4. 원본 데이터, 정제 데이터, 오류 데이터를 각각 별도 파일로 저장한다.
5. 정제 전후 데이터 건수와 결측치 수를 비교한다.
6. 처리 결과를 preprocessing_report.txt로 저장한다.
7. 실행 중 오류가 발생하면 원인과 해결 방법을 출력한다.
8. 데이터 처리 함수를 기능별로 분리한다.
9. 같은 입력 데이터에 같은 처리 정책을 적용하면 동일한 결과가 나오도록 작성한다.
10. 파일이 없거나 필수 컬럼이 누락된 경우에도 적절한 오류 메시지를 출력한다.
11. 초보자가 이해할 수 있도록 한글 주석과 실행 방법을 작성한다.

최종 파일명은 preprocessing_app.py로 작성해줘.
코드 생성 후 실행하고, 오류가 발생하면 원인을 분석해 수정해줘.
